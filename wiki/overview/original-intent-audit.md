# 원작자 의도 대조표 (Original Intent Audit)

원 개발자와 그의 AI(Bolt.new)의 대화 로그(Version 1 → 98, 2026-10-16 ~ 10-19)를 읽고,
**원작자가 직접 말한 게임성 요구**가 현재 코드(v0.1.0)에 그대로 살아 있는지 점검한 결과.

- 기준: 원작자 본인의 발언(요청·정정·거절). AI가 임의로 설명한 내용은 원작자가 수용했을 때만 의도로 본다.
- 범위: 게임성(규칙·수치 구조·전투 감각). 이번에 추가한 UI·디자인·기능 확장(아이콘, 일시정지, 설정 등)은
  "의도 이탈"로 보지 않는다 (사용자 지시).
- 로그는 구버전이다. 로그 이후 원작자가 바꾼 것이 코드에 있다면 코드가 우선이다.

## 📝 확인 필요 / 참고

| # | 내용 | 메모 |
|---|---|---|
| A | **환영 비도의 부메랑** — 원작자는 v30에서 *기본* 비도를 "부메랑 형이 아니라" 다중 투척·관통으로 바꿨다. 이후 v49에서 AI가 진화형을 "8개 투척, 부메랑 회귀, 관통 무한"으로 설계했고 원작자는 이의 없이 다음 작업으로 넘어갔다. | 진화형 한정이라 유지. 원치 않으면 `ShurikenWeapon.ts` 의 `if (w.evolved)` 부메랑 분기만 끄면 된다. |
| B | **브레스 판정 폭** — 원래는 "굵은 레이저"(±약 11°)였다. 2026-10-20 사용자가 빔 대신 전방 화염 입자로 바꾸라고 했다. 전방만 덮으므로 포위 상황에서는 Lv8 발톱보다 총 피해가 낮을 수 있다. | 입자 퍼짐은 `BreathWeapon.ts` 의 `SPRAY_HALF`. 빔으로 되돌리지 말 것. |
| C | **게임 제목** — 로그와 원본 코드의 제목은 "Vampire Survivors (Style Game) Prototype". 공개 저장소에서 타 게임 상표를 제목으로 쓰지 않으려고 "Survivors"로 바꿨다. | 게임성 아님. `src/gameInfo.ts` 한 줄로 되돌릴 수 있다. |

## 로그에서 읽은 원작자의 취향 (앞으로의 작업 기준)

- **또렷함을 좋아하고 번짐을 싫어한다** — 모션블러·잔상·반투명 엔티티에 여러 번 불만(v84, v86, v90, v91, v98).
  → 이펙트는 짧고 선명하게, 엔티티는 항상 불투명하게.
- **"수치만 오르는" 성장보다 질적 변화**를 원한다(v20) → 레벨별 특수 효과 유지.
- **용어는 범용적으로**(v7), **표기는 "현재 → 강화 후"**(v6, v8).
- **진화형은 최종형**(v71) — 진화 후 레벨업 금지.
- 컨셉을 자주 정정한다(비도 v30, 라이플 v31, 브레스 v83→96) → 무기 컨셉은 원작자 결정 사항으로 남긴다.
