# UI 흐름 (Screens & HUD)

> 코드: `src/App.tsx`, `src/ui/**` · 스크린샷: [design/screenshots](../design/screenshots/)

## 화면 전환

```
              ┌──────────── Lobby ────────────┐
              │ 게임 시작 · 캐릭터 뽑기 · 캐릭터 관리 │
              │ 특성 · 도감 · 업적 · 제약 · 설정   │
              └──┬──────┬──────┬──────┬──────┬──┘
   GameCanvas ◀──┘  Gacha  Characters Traits  Codex/Achievements
   (게임오버 → 다시 시작 | 로비로)   (← 로비로)
```

`App.tsx` 가 `screen` 상태 하나로 전환하고, 세이브(`SaveData`)를 들고 있다가 각 화면에 내려준다.
로비로 돌아올 때마다 `loadSave()` 로 다시 읽는다.

## 인게임 (GameCanvas)

| 영역 | 내용 |
|---|---|
| 상단 바 | 경험치 바 (시안) |
| 좌상단 | 생존 시간 · 처치 · 스코어 · 레벨(XP 수치) |
| 상단 중앙 | 엘리트가 살아 있는 동안 남은 처치 시간(30초, 10초 이하는 빨강) |
| 우상단 | HP 바 (50% 초록 / 25% 노랑 / 그 이하 빨강) |
| 좌상단 아이콘 | 모래시계·해골·별무더기·레벨 아이콘 + 값 |
| 우상단 아래 | 남은 리롤 수 |
| 좌하단 | 보유 무기(무기 아이콘 + 이름 + Lv/MAX, 진화는 금 테두리) + 빈 슬롯 틀, 장신구(아이콘) |
| 캔버스 밖 하단 | 조작 안내 · **일시정지 · 설정** · 게임 포기 |
| 캔버스 표식 | 플레이어 원 안 캐릭터 엠블럼, 엘리트 머리 위 왕관, 보물 상자 아이콘, 처치 시 짧은 별 이펙트 |

- HUD는 엔진이 0.15초마다 보내는 통계로 갱신 (React 렌더 부담 최소화).
- 캔버스는 4:3 비율을 유지하며 `min(960px, 화면 폭, (화면 높이-96px)×4/3)` 로 축소된다.

## 레벨업 모달

LEVEL UP 제목(+대기 수) · 리롤 버튼(남은 횟수, 단축키 R) · 카드 3장(단축키 1/2/3).
카드 = 무기/장신구 아이콘 + 배지(NEW·UP·EVOLVE) + 이름 + 설명(신규면 무기·장신구 설명) + 다음 레벨 효과.
선택하면 즉시 재개(대기 레벨업이 있으면 다음 카드). 모달이 떠 있는 동안 캔버스는 정지 화면 1장만 유지한다.

## 일시정지 메뉴

ESC/P · 포커스 상실 시. 설정 패널(그래픽 품질 3단, 효과음 볼륨·음소거) + 계속하기 + 게임 포기(보상 정산).

## 게임오버

생존 시간 · 처치 · 레벨 · 스코어 · 획득 골드 · (제약 점수와 골드 배율) · (업적 보상 별) — 각 줄에 아이콘.
이번 판에 달성한 업적(진화 무기 아이콘) · 이번 판 무기 목록. [다시 시작] [로비로 돌아가기].

## 로비

우상단 골드·별·설정 버튼, 제목/부제/안내문(`gameInfo.ts`), 플레이 캐릭터 카드(엠블럼·레벨·별·돌파·시작 무기 → 누르면 캐릭터 관리),
메뉴 카드 8개(게임 시작·제약·캐릭터 뽑기·캐릭터 관리·특성·도감·업적·설정, 2열). 우상단 톱니도 설정 화면으로 간다. 하단 조작 안내 · 버전 · 아이콘 작가 크레딧(CC BY 표기).

## 도감

탭 4개: 적(아이콘 + 게임 속 실제 도형·등장 시간·스탯) / 무기(레벨별 피해·쿨다운·특수 효과) / 진화(조건·실제 수치) / 장신구(레벨별 효과).
레벨별 특수 효과는 무기 등록표의 `levelEffect` 를 읽어 레벨업 카드와 항상 일치한다.
